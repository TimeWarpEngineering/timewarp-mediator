# TimeWarp.Mediator 15.0.0-beta.10

A source type can declare requests and handlers that another generator emits, and `Send` dispatches them. Roslyn generators cannot see each other's output. Before this release, a request another generator emitted into the host had no `Send` arm, so `Send` threw `NoHandlerException`. 15.0.0-beta.5 covered only the reverse case: a request written in source naming a handler another generator emits.

## New

`GeneratedRequestPatternAttribute` (in `TimeWarp.Mediator`) goes on a source type. It allows multiple uses and can be derived. It declares, per contract type, a request name, a handler name, and the Mediator interface the request implements:

```csharp
[GeneratedRequestPattern(
  "{Host}.{Contract}ActionSet.Action",
  "{Host}.{Contract}ActionSet.Handler",
  "TimeWarp.Mediator.IRequest<{ContractType}.Response>",
  typeof(CreateRole), typeof(UpdateRole))]
public partial class RoleState { }
```

- Placeholders: `{Host}` (the attributed type's full name), `{Contract}` (the contract's simple name), `{ContractType}` (the contract's full name).
- The request interface fixes the response (`IRequest<T>` argument, or void for `IAction` and `IRequest`). It also lets a behavior constrained on that interface, such as `where TRequest : IAction`, close over the declared request.
- A derived attribute passes its templates as constructor parameters with the same names or declares them as `const string` fields (`RequestTypeName`, `HandlerTypeName`, `RequestInterfaceName`). Its contracts are a constructor parameter named `contracts`. Const fields survive in a reference assembly.

Each expansion gets the same `Send` arm, handler call, and woven behaviors as a request written in source. The pipeline comes from the nearest existing containing type's `[MediatorScope]`, else the assembly's.

## Diagnostics

TWM013 is new. The generator reports it when a pattern cannot be read or expanded. The analyzer reports it in a host after every generator has run, when a declared request or handler does not exist, the request does not implement the declared interface, or the handler is not that request's `IRequestHandler`.
