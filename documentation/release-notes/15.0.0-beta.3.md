# TimeWarp.Mediator 15.0.0-beta.3

The packages need a .NET SDK whose compiler is at least the Roslyn version they reference (11.0.100 or later; a 10.0.x band only if its compiler is at least that version); an older SDK reports CS8032/CS9057 and the generator emits nothing.

`Microsoft.CodeAnalysis.CSharp` and `Microsoft.CodeAnalysis.CSharp.Workspaces` follow that rule. `ReferencedCompiler_IsNotNewerThanTheSdkCompiler` fails when the shipped generator references a `Microsoft.CodeAnalysis` assembly newer than the SDK compiler in `global.json`.
