# TimeWarp.Mediator 15.0.0-beta.7

The dispatcher is unchanged since 15.0.0-beta.6. This prerelease targets `net11.0` only, moves the build from the .NET 11 release candidate to the .NET 11 GA SDK and packages, and stamps `<Version>` as `15.0.0-beta.7`.

## Breaking

- `TimeWarp.Mediator` now targets `net11.0` only. The `lib/net10.0` asset is gone. `net10.0` consumers must stay on 15.0.0-beta.6 or earlier.
- `TimeWarp.Mediator.Generators` and the TWM001–TWM004 and TWM012 analyzer inside `TimeWarp.Mediator` move from `netstandard2.0` to `net11.0`. The compiler that loads them must run on .NET 11. Build with the .NET 11 SDK (`dotnet build`). Visual Studio and .NET Framework MSBuild are not supported.

## Build

`global.json` pins the SDK to `11.0.100` with `rollForward: latestFeature`. The `rc.3` band and `allowPrerelease` are gone. CI installs only `11.0.x` on the GA channel, without `dotnet-quality: preview`. The `10.0.x` install is gone.

The tests, benchmarks, samples, and package smoke consumer target `net11.0` only. `./bin/dev pack` requires exactly `lib/net11.0` in `TimeWarp.Mediator` and runs the smoke consumer once, on `net11.0`. RS1041 (a compiler extension should target `netstandard2.0`) is turned off in the generator and analyzer projects only.

`TimeWarp.Mediator` still has no NuGet dependencies. Its `lib/net11.0` asset is now compiled by the GA SDK against the GA `net11.0` targeting pack. The central pins in `Directory.Packages.props` serve this repository's test, benchmark, sample, and smoke hosts. `Microsoft.Extensions.DependencyInjection` moves from `11.0.0-rc.3.26522.148` to `11.0.0`, and `Microsoft.Extensions.Logging` moves with it. The `net10.0`-conditioned `10.0.x` pins are removed.

The build and test pins move too. None of them ships in either package:

`TimeWarp.Build.Tasks` 2.0.0 ships its MSBuild task for `net11.0` only. A .NET Framework MSBuild (Visual Studio, `MSBuild.exe`) cannot load it and stops with `TWBT0001`. This repository does not work around that, because those hosts cannot load the `net11.0` generator and analyzer either. `dotnet build` on the pinned 11.0.100 SDK stamps `CommitHash` and `CommitDate` assembly metadata.

`TimeWarp.SourceGenerators` 1.0.0-beta.13 adds TWA0004 (`#region Purpose` in every C# file) and TWA0038 (500-line file cap). The `TimeWarp.Mediator` interface files, and the global-usings and assembly-info files in the tests and samples, gain a `#region Purpose` block. The public API does not change. The dev CLI runfile (`tools/dev-cli/dev.cs`) turns TWA0038 off for its own build only, because two files that `TimeWarp.Nuru.DevCli` 4.0.0-beta.12 compiles in are over the cap. Products, tests, and samples still enforce it.

`coverlet.collector` stays because `./bin/dev test` collects Cobertura coverage with `--collect:"XPlat Code Coverage"`. 8.0.0 raised its floor to .NET 8, which this repository already exceeds.

## Benchmarks

BenchmarkDotNet is pinned to `0.16.0-preview.2`. `0.15.8` throws on a net11.0 host before it measures, and `0.16.0` stable is not on nuget.org yet. The regression gate (`./bin/dev benchmark --gate`) moves from `net10.0` to `net11.0`. `documentation/benchmarks/comparison-baseline.md` is re-recorded on `net11.0` and is the gate file. `comparison-baseline-net11.md` is removed. `comparison-baseline-aot.md` is re-recorded on `net11.0`. The gate thresholds are unchanged: mean time at most 50% above the recorded mean, and no extra allocated bytes.

Release after merge is `./bin/dev release` from a clean synced master. This task does not tag or push packages.
