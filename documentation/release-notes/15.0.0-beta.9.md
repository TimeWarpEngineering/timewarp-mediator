# TimeWarp.Mediator 15.0.0-beta.9

The dispatcher is unchanged since 15.0.0-beta.8. This prerelease targets `net11.0` only and stamps `<Version>` as `15.0.0-beta.9`. 15.0.0-beta.8 was the last release that carries `lib/net10.0` and a `netstandard2.0` generator and analyzer.

## Breaking

- `TimeWarp.Mediator` now targets `net11.0` only. The `lib/net10.0` asset is gone. `net10.0` consumers must stay on 15.0.0-beta.8 or earlier.
- `TimeWarp.Mediator.Generators` and the TWM001–TWM004 and TWM012 analyzer inside `TimeWarp.Mediator` move from `netstandard2.0` to `net11.0`. They load only in the `dotnet` SDK compiler, which runs on .NET 11. Build with the .NET 11 SDK (`dotnet build`). Visual Studio and .NET Framework MSBuild are not supported.

## Build

CI installs only `11.0.x` on the GA channel. The `10.0.x` install is gone.

The tests, benchmarks, samples, and package smoke consumer target `net11.0` only. `./bin/dev pack` requires exactly `lib/net11.0` in `TimeWarp.Mediator` and runs the smoke consumer once, on `net11.0`. RS1041 (a compiler extension should target `netstandard2.0`) is turned off in the generator and analyzer projects only.

The `net10.0`-conditioned pins in `Directory.Packages.props` are removed. `Microsoft.Extensions.DependencyInjection` and `Microsoft.Extensions.Logging` are each pinned once, at `11.0.0`.

The dev CLI pins move to the latest prereleases (`ganda repo audit --fix`): `TimeWarp.Nuru` and `TimeWarp.Nuru.DevCli` `4.0.0-beta.13` to `4.0.0-beta.14`, `TimeWarp.Amuru` and `TimeWarp.Amuru.Tools` `3.0.0-beta.2` to `3.0.0-beta.4`, and `TimeWarp.Terminal` `2.0.0-beta.1` to `2.0.0-beta.2`. None ships in either package.

`TimeWarp.Build.Tasks` ships its MSBuild task for `net11.0` only, so a .NET Framework MSBuild stops with `TWBT0001`. This repository does not work around that, because those hosts cannot load the `net11.0` generator and analyzer either.

## Benchmarks

BenchmarkDotNet is pinned to `0.16.0-preview.2`. `0.15.8` throws on a net11.0 host before it measures, and `0.16.0` stable is not on nuget.org yet. The regression gate (`./bin/dev benchmark --gate`) moves from `net10.0` to `net11.0`. `documentation/benchmarks/comparison-baseline.md` is re-recorded on `net11.0` and is the gate file. `comparison-baseline-net11.md` is removed. `comparison-baseline-aot.md` is re-recorded on `net11.0`. The gate thresholds are unchanged: mean time at most 50% above the recorded mean, and no extra allocated bytes.

Release after merge is `./bin/dev release` from a clean synced master. This task does not tag or push packages.
