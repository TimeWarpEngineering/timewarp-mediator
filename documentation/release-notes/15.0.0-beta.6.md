# TimeWarp.Mediator 15.0.0-beta.6

The dispatcher is unchanged since 15.0.0-beta.5. This prerelease refreshes the central package pins and stamps `<Version>` as `15.0.0-beta.6`.

`TimeWarp.SourceGenerators` moves from `1.0.0-beta.11` to `1.0.0-beta.12`. The package stays a private build asset. It still depends on `Microsoft.CodeAnalysis.CSharp` 4.11.0. The generator project, the analyzer project, and their test hosts remove the `TimeWarp.SourceGenerators` reference so its generators do not run inside those Roslyn components. Beta.12 drops the unused interface-delegation generator and the markdown sidecar for XML documentation. This repository does not use either.

`TimeWarp.Nuru` and `TimeWarp.Nuru.DevCli` move from `4.0.0-beta.11` to `4.0.0-beta.12`. Nuru beta.12 ships `lib/net11.0` only and depends on Mediator `15.0.0-beta.4`, so the dev CLI target framework moves from `net10.0` to `net11.0`. Local endpoint handlers implement `IRequestHandler<TCommand, Unit>` and return `ValueTask<Unit>`, which is the contract DevCli beta.12 already uses.

The other pins in `Directory.Packages.props` are already the latest version on their channel at nuget.org. A stable pin stays on the latest stable. A prerelease pin stays on the latest prerelease. `TimeWarp.Amuru` and `TimeWarp.Amuru.Tools` stay at `2.0.0`. `TimeWarp.Terminal` stays at `1.0.2`. `Microsoft.Extensions.DependencyInjection` on `net10.0` stays at `10.0.14`, the latest `10.0.x` patch, so a net10.0 host does not restore an 11 package. `Microsoft.Extensions.Logging` matches that split: `10.0.14` on `net10.0` and `11.0.0-rc.3.26522.148` on `net11.0`.

`Microsoft.CodeAnalysis.CSharp` and `Microsoft.CodeAnalysis.CSharp.Workspaces` stay at `5.9.0`. That is the latest stable on nuget.org. The SDK in `global.json` (`11.0.100-rc.3`) loads Roslyn assembly version `5.12.0.0`, and `5.9.0` is not newer than that compiler. `ReferencedCompiler_IsNotNewerThanTheSdkCompiler` is the check.

Task 023-001 owns the `global.json` SDK pin, the `net11.0` `Microsoft.Extensions.DependencyInjection` release candidate (`11.0.0-rc.3.26522.148`), the CI `dotnet-quality: preview` line, and both BenchmarkDotNet pins (`0.15.8` on `net10.0`, `0.16.0-preview.2` on `net11.0`). Those values stay. `tools/dev-cli/dev.cs` has no `#:package` directive.

Release after merge is `./bin/dev release` from a clean synced master. This task does not tag or push packages.
