# TimeWarp.Mediator 15.0.0-beta.5

A request in source can name a handler that another generator emits. Roslyn generators cannot see each other's output, so a handler TimeWarp.State generates was never dispatched. `GeneratedHandlerAttribute` is the declared fact. It is public and abstract. A derived attribute supplies `HandlerTypeName`, a constant type name relative to the request's containing type (or the request's namespace when the request is top-level). The host candidate extractor accepts that attribute, including attributes found by walking base types, and the dispatcher emits a call to that name. Generated code may reference generated code, because every generator's output compiles together.

When the name is not a constant, the generator reports TWM012 on the attribute. When the named handler still does not exist after every generator has run, the analyzer reports TWM012 on the attribute, including in a generator host. A library does not report that missing type: the host is where the other generator emits it. Requests without the attribute are unchanged, including the unrelated-edit incrementality cache.

TimeWarp.State pins this version for its half of the same change.
