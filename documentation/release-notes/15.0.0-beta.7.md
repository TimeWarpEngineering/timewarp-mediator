# TimeWarp.Mediator 15.0.0-beta.7

The dispatcher is unchanged since 15.0.0-beta.6. This prerelease moves the build from the .NET 11 release candidate to the .NET 11 GA SDK and packages, and stamps `<Version>` as `15.0.0-beta.7`.

`global.json` pins the SDK to `11.0.100` with `rollForward: latestFeature`. The `rc.3` band and `allowPrerelease` are gone. CI installs `11.0.x` on the GA channel without `dotnet-quality: preview`, and still installs `10.0.x` so the `net10.0` targeting pack and runtime restore.

`TimeWarp.Mediator` still has no NuGet dependencies. Its `lib/net11.0` asset is now compiled by the GA SDK against the GA `net11.0` targeting pack. The central pins in `Directory.Packages.props` serve this repository's test, benchmark, sample, and smoke hosts. On `net11.0`, `Microsoft.Extensions.DependencyInjection` moves from `11.0.0-rc.3.26522.148` to `11.0.0`, and `Microsoft.Extensions.Logging` moves with it. On `net10.0`, both move from `10.0.14` to `10.0.15` and stay on the 10.0 line, so a net10.0 host does not restore an 11 package.

The build and test pins move too. None of them ships in either package:

| Package | From | To |
|---|---|---|
| `Microsoft.SourceLink.GitHub` | `10.0.403` | `11.0.100` |
| `TimeWarp.Build.Tasks` | `1.0.0` | `2.0.0` |
| `TimeWarp.SourceGenerators` | `1.0.0-beta.12` | `1.0.0-beta.14` |
| `Microsoft.NET.Test.Sdk` | `18.11.0` | `18.12.0` |
| `coverlet.collector` | `6.0.4` | `10.1.0` |

`TimeWarp.Build.Tasks` 2.0.0 ships its MSBuild task for `net11.0` only. A .NET Framework MSBuild (Visual Studio, `MSBuild.exe`) cannot load it and stops with `TWBT0001`. `Directory.Build.props` sets `TimeWarpEnableGitMetadata=false` when `$(MSBuildRuntimeType)` is not `Core`, so those builds still compile but carry no `CommitHash` or `CommitDate` assembly metadata. `dotnet build` on the pinned 11.0.100 SDK still stamps both.

`TimeWarp.SourceGenerators` 1.0.0-beta.13 adds TWA0004 (`#region Purpose` in every C# file) and TWA0038 (500-line file cap). The `TimeWarp.Mediator` interface files, and the global-usings and assembly-info files in the tests and samples, gain a `#region Purpose` block. The public API does not change.

`coverlet.collector` stays because `./bin/dev test` collects Cobertura coverage with `--collect:"XPlat Code Coverage"`. 8.0.0 raised its floor to .NET 8, which this repository already exceeds.

BenchmarkDotNet stays on `0.15.8` for `net10.0`, the tool that recorded `documentation/benchmarks/comparison-baseline.md`, and on `0.16.0-preview.2` for `net11.0`. `0.15.8` throws on a net11.0 host before it measures, and `0.16.0` stable is not on nuget.org yet. `comparison-baseline.md` is not re-recorded. `./bin/dev benchmark --gate` still runs against it.

Release after merge is `./bin/dev release` from a clean synced master. This task does not tag or push packages.
